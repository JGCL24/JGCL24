## 💫 Sobre mim

Sou estudante de **Engenharia de Software na Universidade Federal do Ceará (UFC – Campus Quixadá)**, com experiência prática construindo sistemas de ponta a ponta — desde APIs em Python/FastAPI com autenticação e banco de dados, até interfaces em React/TypeScript e JavaScript puro. Gosto de transitar entre back-end, front-end e QA, sempre buscando escrever código limpo, testável e que resolva problemas reais.

- 🔭 Atualmente desenvolvendo o **SIGBRO**, um back-end em FastAPI com autenticação via Supabase, com suíte de testes automatizados em pytest
- 🎨 Também trabalhei em projetos front-end como o **B-R-O-Bró**, um catálogo de produtos com JavaScript, Tailwind CSS e Supabase Storage
- 🧪 Tenho interesse forte em **Qualidade de Software (QA)** — testes unitários, BDD/Gherkin, cobertura de código e boas práticas de verificação e validação
- 💡 Também curioso por **empreendedorismo**, já explorei um conceito de startup para centralizar anúncios de moradia estudantil no Brasil
- 🎓 Formação sólida em algoritmos, estruturas de dados e grafos, com trabalhos formais sobre complexidade e técnicas de divisão e conquista
- 💼 Em busca de oportunidades de estágio em desenvolvimento de software

> *"O melhor código é aquele que resolve problemas reais de forma simples."*
